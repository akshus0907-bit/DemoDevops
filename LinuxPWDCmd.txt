COMMAND: PWD

FULL FORM: Print Working Directory

================================================================================

1. WHAT IS PWD?

================================================================================

The `pwd` command stands for "Print Working Directory".

It is used to display the complete path of the directory in which

we are currently working.
In simple words: &#x20;   pwd tells us:  "Where am I currently located in the Linux file system?"
\--------------------------------------------------------------------------------

EXAMPLE

\--------------------------------------------------------------------------------
COMMAND: pwd
OUTPUT: /home/Akshata

MEANING: The current working directory is /home/Akshata.


================================================================================

2. WHY DO WE USE PWD?

================================================================================

Linux has a hierarchical file system containing directories and files.

While working in Linux, we may move between different directories

using the `cd` command.

Therefore, we need to know our current location.

The `pwd` command helps us identify our current location.

It is especially useful before performing operations such as:

   cd
   mkdir

  touch

  cp

  mv

  rm

--------------------------------------------------------------------------------

EXAMPLE

--------------------------------------------------------------------------------

COMMAND: pwd

OUTPUT:  /home/Akshata

INTERPRETATION:

  /              -> Root directory**

 home           -> Home directory**
Akshata        -> User's home directory**

Therefore:   /home/Akshata

is the current working directory.

3. MAN PWD

================================================================================

COMMAND: man pwd

FULL FORM:man = Manual

PURPOSE:  &#x20;   The `man pwd` command opens the manual/documentation

&#x20;   of the `pwd` command.

The manual provides detailed information about the command,

including:
   - Command name

   - Syntax

   - Description

   - Options

  - Other technical information

--------------------------------------------------------------------------------
EXAMPLE

--------------------------------------------------------------------------------

COMMAND: man pwd

ACTION: PWD(1)                                             General Commands Manual                                                        PWD(1)

NAME

pwd - Display the full filename of the current working directory.

SYNOPSIS

     pwd \[-L|--logical] \[-P|--physical] \[-h|--help] \[-V|--version]

DESCRIPTION

      Display the full filename of the current working directory.

OPTIONS

      -L, --logical

       use PWD from environment, even if it contains symlinks

      -P, --physical

      avoid all symlinks

       -h, --help

       Print help

      -V, --version

Print version :VERSION  v(uutils coreutils) 0.8.0The pwd manual page opens in the terminal.

TO EXIT:

   Press q

4. HELP PWD

================================================================================
COMMAND: help pwd

PURPOSE:    The `help pwd` command displays the Bash built-in help information for the `pwd` command. Your Bash system shows:

  pwd: pwd \[-LP]

This means that the Bash built-in `pwd` supports:

  -L

  -P

--------------------------------------------------------------------------------

EXAMPLE

--------------------------------------------------------------------------------

COMMAND: help pwd

IMPORTANT OUTPUT:pwd: pwd \[-LP]

  Print the name of the current working directory.

  Options:

    -L        print the value of $PWD if it names the current working

              **directory**

    -P        print the physical directory, without any symbolic links


   By default, `pwd' behaves as if `-L' were specified.

  Exit Status: Returns 0 unless an invalid option is given or the current directory

  cannot be read.

  pwd: pwd \[-LP]

  -L    print the value of $PWD if it names the current
       **working directory**

  -P    print the physical directory, without any
         symbolic links

5. PWD -L

================================================================================

COMMAND: pwd -L

FULL FORM: -L = Logical

PURPOSE:   The `-L` option displays the logical path of the  current working directory.

It uses the value of the `$PWD` environment variable

when it correctly represents the current directory.

By default, Bash `pwd` behaves as if `-L` was specified.

--------------------------------------------------------------------------------

EXAMPLE

--------------------------------------------------------------------------------
COMMAND: pwd -L
OUTPUT: /home/Akshata
MEANING:   **The logical path of the current directory is: /home/Akshata

================================================================================

6. PWD -P

================================================================================

COMMAND: pwd -P

FULL FORM:  -P = Physical

PURPOSE:  The `-P` option displays the physical/actual path  of the current working directory.

It does not use symbolic links.If symbolic links are involved, `-P` resolves them and shows the actual physical directory path.


--------------------------------------------------------------------------------

EXAMPLE

--------------------------------------------------------------------------------

COMMAND:  pwd -P

OUTPUT:  /home/Akshata
MEANING:  The physical path of the current directory is:  /home/Akshata

===============================================================================

7. DIFFERENCE BETWEEN -L AND -P

================================================================================

+----------------------+-----------------------------------------------+

| OPTION               | MEANING                                       |

+----------------------+-----------------------------------------------+

| -L                   | Logical path                                  |

| -P                   | Physical/actual path                          |

+----------------------+-----------------------------------------------+



In your current directory:

  pwd -L

  /home/Akshata

  pwd -P

  /home/Akshata

Both commands give the same output because there is

no symbolic-link difference in your current location.

The difference becomes important when symbolic links

are involved.

================================================================================

8. PWD -LP

================================================================================



COMMAND:  pwd -LP

PURPOSE:   This command provides both the `-L` and `-P` options  together. Your system accepts this command.

\--------------------------------------------------------------------------------

EXAMPLE

\--------------------------------------------------------------------------------

COMMAND:  pwd -LP

OUTPUT:  /home/Akshata
NOTE:

  For beginners, learn these separately first:

     pwd -L

     pwd -P

 Then understand that options can also be combined.

================================================================================

9. PWD --VERSION

================================================================================

COMMAND TESTED:  pwd --version
STATUS: DOES NOT WORK ON YOUR BASH

--------------------------------------------------------------------------------

OUTPUT FROM YOUR SYSTEM

--------------------------------------------------------------------------------


  -bash: pwd: --: invalid option

  pwd: usage: pwd \[-LP]

--------------------------------------------------------------------------------

WHY DOES IT NOT WORK?

--------------------------------------------------------------------------------

Your `pwd` command is the Bash built-in `pwd`.

The Bash built-in `pwd` supports:

  -L

 -P

It does NOT support:  --version

THEREFORE:

  pwd --version

   NOT SUPPORTED BY YOUR BASH PWD

  Bash has its own built-in implementation of `pwd`.

This is why some options found in other documentation

may not work with the Bash built-in version.
